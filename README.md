# Shard: Test Build

**Shard** is a top-down bullet-hell roguelite where you don't pick your upgrades, **you build them** from fragments enemies drop, mid-fight. This repository hosts the private playtest build.

## Links

- **Play the web build:** https://255-ping.github.io/shard-test-build/
- **Tester Guide:** [TESTER_GUIDE.md](TESTER_GUIDE.md)
- **Discord (feedback & bug reports):** https://discord.gg/zQ7cfvm6hP

## Getting started

1. Open the **web build** link above in your browser.
2. If prompted, enter the **build password** you were given and press **Unlock**.
3. Read the **[Tester Guide](TESTER_GUIDE.md)** first. It covers the controls, how to play, what to test, and what is intentionally unfinished (so you don't report it as a bug).
4. Report anything you find in the **Discord**.

## What's in this build

- 6 base forms: Projectile, Nova, Beam, Trap, Aura, Summon
- 25 modifiers across 6 families (behavioral, stat, fire, ice, void, light)
- 11 wildcard fragments with full reveal animation
- 3 bosses: The Pyre, The Hollow, The Permafrost
- Boss Rush mode (all 3 bosses in sequence)
- Elite enemies with guaranteed drops
- Full crafting and decraft system
- 30 wired perks across 5 skill trees
- Soft persistence (character, loadout, fragments carry between runs)
- Custom run builder (1:00 to 12:00, configurable boss/density/modifiers)
